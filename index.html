The Floor

Portable · transfers to every vendor

Free-weight work. Everything here is ANSI SQL or core Postgres, so it survives a migration from Neon to Supabase to Aurora to a box under your desk. Write a query, run it, and the checker compares your result against a reference answer — any query that returns the right rows passes.

About the seed data. Two tables, vendors and rounds, holding the database market itself as reported on 27 July 2026. Only figures stated in the source reporting are present; everything undisclosed is NULL rather than guessed. Half the difficulty in real SQL comes from missing values, so the drills lean into it.

The Machines

Vendor-specific · check the transfer rating

Each machine trains one thing well and holds part of your work captive. The transfer rating estimates how much of what you learn and build survives a move to a different supplier: blue leaves with you, magenta stays behind. Ratings are editorial judgements about query-language portability and migration cost, not vendor claims.

The Spotters

Which AI platform reaches which database

Vercel gave up running its own storage and became a broker, provisioning other people's databases from inside its marketplace. It has company. Three patterns dominate: a platform ships one database and hides the wiring (native), a coding agent talks to whatever you own through Model Context Protocol (MCP), or you paste a connection string yourself (BYO).

AI platformReachesHowWhat it means for you
Read the MCP row carefully. An agent with write access to a production database is a new class of hazard. Every serious database MCP server ships a read-only mode; start there, scope credentials to one project or schema, and grant writes only against a database you can restore.

What this prototype is

A working skeleton: real Postgres in the browser via PGlite, eight drills with automatic checking, fourteen platform cards, and a connection matrix. Curriculum, accounts, and progress persistence are not built. Vendor facts carry a date and will rot — pricing, ownership and feature claims in this market change monthly.
